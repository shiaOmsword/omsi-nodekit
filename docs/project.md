# omsi-nodekit 
## Описание проекта
Набор утилит и инструментов для работы с 3x-ui. Создание inbound, outbounds, tags resolvers, balancers

Представляет из-себя панель управления, которая открывается локально на устройстве пользователя и позволяет
подключаться к настраиваемой ноде через ssh. Для этого нужен предварительно настроенный пользователь, желательно с
sudo правами. Работа протестирована на ubuntu 24.04. 

## Режимы для работы
### Fresh | clean
Для установки на чисто настроенную ноду. Устанавливает 3x-ui, создает inbound, inbound по конфигу.
Создает несколько тестовых пользователей. Поднимает 3x-ui через docker панель, подключается к общей docker network.
Создает отдельный конфиг для caddy. Затем подключает этот конфиг в Caddyfile. (Поддерживает работу caddy в двух режима как докер
контейнер и как общей системный процесс)

### Restore
Для восстановления данных из дампа. Поддерживает возможность восстановиться из дампа omsi-nodekit, если такой конечно был сделан когда-то.
Есть возможность восстановиться из дампа 3x-ui.db. 

### Observe mode? (Если 3x-ui уже установлена), то имеется возможность подключиться через api ключ и подгрузить найстройки в nodekit.

### Backup | Rescue 
Спасательный режим, для создания дампов, сохранения дампов базы. (Программа и так делает бекап всей системы после первого подключения и после применения критических изменений, а также на выходе из системы.)
