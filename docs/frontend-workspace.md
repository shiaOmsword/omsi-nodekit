# Интерфейс рабочего пространства Nodekit

Интерфейс разделён на страницы. Главная открывается как dashboard, а
операции над сервером доступны из карточки конкретной ноды.

| Раздел | Адрес | Содержимое |
| --- | --- | --- |
| Обзор | `#/dashboard` | Число нод, активные задачи, бэкапы и последние операции |
| Ноды | `#/nodes` | Поиск, активные/скрытые/архив, создание и управление |
| Карточка ноды | `#/nodes/:id` | Подключение и последний отчёт обнаружения |
| Операции ноды | `#/nodes/:id/operations/:action` | Отдельный экран обнаружения, диагностики, Fresh, Restore или Backup |
| Конфигурация | `#/nodes/:id/config` | Формы подключения/развёртывания и расширенный YAML |
| История ноды | `#/nodes/:id/history` | Только задачи выбранной ноды |
| Операции | `#/operations` | Общий журнал с фильтрами и переходом к результату |
| Результат | `#/operations/:job-id` | Статус, ошибка, отчёт и скачивание бэкапа |
| Подписки и ключи | `#/subscriptions` | Клиенты VLESS/WG, диагностика подписок и контролируемый сброс серверного кэша |
| Бэкапы | `#/backups` | Загрузка, скачивание, манифест и выбор ноды для Restore |
| SSH-ключи | `#/keys` | Создание, публичная часть, назначение и удаление |
| Логи | `#/logs/:job-id` | Живой лог, уровни, поиск, автопрокрутка и экспорт |
| Справка | `#/help` | Существующие инструкции |

Маршрутизация использует hash, поэтому прямые ссылки и перезагрузка работают
с существующим FastAPI StaticFiles без нового серверного роутера.

## Общие модалки и формы

`framework/components/Modal.tsx` содержит одну основу на нативном HTML
`dialog`. Она обеспечивает modal focus, Escape, backdrop, заголовок,
прокрутку тела и возврат фокуса. Во время запроса закрытие и повторные
отправки блокируются. `FormDialog` собирает поля из типизированного описания:
text, password, number, select, checkbox, textarea.

На этой основе работают подключение ноды, параметры установки, подстановка
по отчёту, SSH-ключи, привязки, загрузка/восстановление бэкапа, план операции
и подтверждения. SSH-ключ можно создать внутри формы ноды без потери полей.
Публичная часть показывается сразу, приватная остаётся в прежнем хранилище.

Сохранение выполняется через существующие API и серверную валидацию.
Редактор YAML остаётся в расширенной конфигурации; смена страницы и закрытие
вкладки защищают несохранённый текст. При отмене перехода текст сохраняется,
при подтверждённом сбросе возвращается сохранённый YAML.

План запуска всегда показывается до POST jobs. Используется revision
конфигурации, полученный от сервера. Restore отправляет выбранный backup_id.
Повторная мутация блокируется в клиенте; серверные проверки остаются
окончательным источником истины.

## Отчёт обнаружения

Вначале показан результат для панели и Caddy. Параметры, сертификаты,
системные инструменты и шесть вариантов размещения раскрываются отдельно.
Отсутствие панели не считается ошибкой выбора. При неполной инвентаризации
интерфейс показывает неизвестное состояние вместо утверждения, что панели нет.
Наличие инструментов не означает готовность портов, DNS, TLS или VPN-трафика.

Подстановка проверяет соответствие отчёта текущему SSH-адресу. Если панели
ещё нет, вручную заданные inbound и выбранный runtime не теряются из-за
стартовых значений API. Найденные параметры Caddy берутся из отчёта; конфликты
по-прежнему проверяет backend. Кнопка явно сообщает о сохранении изменений.

## Визуальная система

Референс: [Railway на Inspo](https://inspomcp.dev/screens/railway-com).
Использованы тёмные индиговые поверхности, сдержанный фиолетовый акцент,
контрастный текст и крупнее элементы управления. Слоганы удалены.

- Основной текст: 16 px, подписи 13–15 px, заголовок страницы 30 px.
- Inter 400/500/600 поставляется локально через `@fontsource/inter`.
- YAML читается/пишется библиотекой `yaml`; финальное решение за API валидации.
- На телефоне все разделы доступны через меню «Разделы», формы идут в одну колонку.
- Таблицы и код прокручиваются внутри своих контейнеров.

Скрытие, архивирование и удаление локальной записи ноды не останавливают VPS.
Удалённые операции имеют отдельные планы и проверки на backend.
